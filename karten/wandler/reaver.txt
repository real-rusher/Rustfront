# REAVER - der Standard. Vier Beine, vier Decks.
#
# Bauform eines Schlachtschiffs: breiter Kasten mit ausgestellten
# Schultern, stumpfer Bug. Die Form eines Dings, das Feuer aushalten soll,
# nicht eines, das ausweicht.
#
# Vier Beine im Kreuzgang: drei tragen immer, waehrend eines tritt.
# Deshalb steht er statisch und kann auf der Stelle halten, ohne zu
# balancieren. Eine volle Drehung dauert 33 Sekunden.
#
# Er vertraegt ein verlorenes Bein. Zwei auf derselben Seite nicht: dann
# liegt sein Rumpf neben der Flaeche, die die uebrigen Fuesse aufspannen.

bein: -5.0 -5.4 links
bein: -5.0  5.4 rechts
bein:  4.2 -5.4 links
bein:  4.2  5.4 rechts
